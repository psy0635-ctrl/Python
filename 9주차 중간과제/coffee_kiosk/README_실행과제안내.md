# 커피매장 주문용 키오스크

## 1. 제작 내용

Python의 tkinter로 커피매장 주문 프로그램을 작성하였습니다. 커피와 차 메뉴를 구분하고, 온도와 용량, 추가 옵션에 따라 결제 금액이 달라지도록 구성하였습니다. 메뉴를 주문 내역에 담은 뒤 결제하면 주문번호와 영수증을 표시합니다.

이 프로그램은 수업용 모의 결제 프로그램입니다. 실제 카드 결제 기능은 없습니다. 주문번호는 실행 중 001부터 증가하며, 프로그램을 종료하고 다시 실행하면 001부터 시작합니다.

## 2. 과제 조건 확인

| 과제 조건 | 구현 내용 |
|---|---|
| 두 종류 이상의 메뉴 탭과 사진 | 커피 탭: 아메리카노·카페라떼 / 차 탭: 홍차·녹차. 각 메뉴 사진 표시 |
| HOT, ICE 선택 | 라디오버튼으로 선택, ICE는 500원 추가 |
| 용량 선택 | Small 355mL / Medium 473mL / Large 591mL |
| 추가 옵션 | 샷 500원, 시럽 300원. 차에서는 샷 선택 불가 |
| 결제 금액 산출 | 기본 가격에 온도·용량·옵션 추가 금액을 합산하고 수량을 곱함 |
| 주문번호 표기 | 결제 완료 시 영수증과 안내창에 표시. 다음 주문번호 증가 |
| 소스코드 및 화면 캡처 제출 | coffee_kiosk.py / screenshots 폴더의 PNG 3장 |

유자차와 카모마일은 과제에 제시된 예시이며, 이 프로그램에서는 차 메뉴를 홍차와 녹차로 구성하였습니다. 가격은 실습을 위해 정한 금액입니다.

## 3. 실행 방법 — Windows

**ZIP 전체 압축 해제 → images 폴더 유지 → coffee_kiosk.py 실행**

1. 받은 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다.
2. 압축을 푼 폴더 안에서 `coffee_kiosk.py`와 `images` 폴더가 함께 있는지 확인합니다.
3. `coffee_kiosk.py`를 IDLE에서 연 뒤 **F5**를 누릅니다.
4. VS Code를 사용한다면 **파일 → 폴더 열기**에서 이 폴더를 엽니다. **터미널 → 새 터미널**에서 아래 명령을 입력합니다.

```powershell
python coffee_kiosk.py
```

일반적인 Windows용 Python 3와 Tcl/Tk가 이미 설치된 환경을 전제로 합니다. 별도 pip 패키지는 필요하지 않습니다. 2026-10-19에 Windows 11 / Python 3.14.7 / Tcl/Tk 9.0.4에서 실행을 확인했습니다. IDLE과 VS Code는 선택 가능한 실행 도구이며, 프로그램 실행에 VS Code 설치가 필요하지는 않습니다. 브라우저나 Colab 셀에서 실행하는 프로그램은 아닙니다.

사용하는 import는 `pathlib.Path`, `tkinter`, `tkinter.ttk`, `tkinter.messagebox`뿐이며 모두 Python 기본 모듈입니다. Pillow/PIL 등 외부 패키지, API 키, 외부 서버, 인터넷 연결, 데이터베이스, 별도 실행 프로그램에 의존하지 않습니다. 사진은 Tk가 직접 읽을 수 있는 PNG 4장으로 포함되어 있습니다. 개발 중 사진 가공이나 검증에 사용한 도구는 최종 프로그램의 실행 의존성이 아닙니다.

Python 자체가 설치되지 않은 PC에서는 `.py` 파일만으로 실행할 수 없습니다. 그런 PC에서도 추가 설치 없이 실행해야 한다는 요구라면 Python 실행 환경을 포함한 별도 배포물이 필요하며, 현재 제출물은 그 경우를 대상으로 하지 않습니다.

사진은 실행할 때 인터넷으로 내려받지 않고 images 폴더에서 읽습니다. 파일을 옮길 때는 폴더 전체를 함께 옮깁니다. 화면 배율 때문에 창 아래쪽이 안 보이면 Windows 디스플레이 배율이나 해상도를 조정해주세요. 기본 창의 크기는 1080×700입니다.

## 4. 사용 순서와 가격 확인 예시

1. **커피 탭 → 아메리카노 사진**을 누릅니다.
2. **ICE / Large / 샷 추가 / 시럽 추가 / 수량 2**를 선택합니다.
3. 한 잔 가격이 **4,800원**, 두 잔 가격이 **9,600원**인지 확인하고 **주문 담기**를 누릅니다.
4. **차 탭 → 홍차 사진**을 누릅니다. 메뉴를 바꾸면 옵션은 HOT·Small·추가 없음·1잔으로 초기화됩니다. 차에서는 샷 선택이 비활성화됩니다.
5. 기본 홍차 1잔을 담으면 총액은 **12,600원**입니다.
6. **결제하기 → 아니요**를 누르면 주문 내역이 유지됩니다.
7. 다시 **결제하기 → 예**를 누르면 주문번호 **001**과 결제 금액을 확인할 수 있습니다.
8. 완료 안내창을 닫으면 오른쪽에 영수증이 남고, 다음 주문번호는 **002**가 됩니다. 주문 내역과 총액은 다음 손님을 위해 초기화됩니다.

계산식:

- 아메리카노: (2,500 + ICE 500 + Large 1,000 + 샷 500 + 시럽 300) × 2 = 9,600원
- 홍차: (3,000 + HOT 0 + Small 0) × 1 = 3,000원
- 전체 결제 금액: 9,600 + 3,000 = 12,600원

## 5. 주요 코드 설명

| 코드 | 설명 | 역할 |
|---|---|---|
| MENUS | 메뉴 이름·가격·사진 파일을 저장한 딕셔너리 | 탭과 메뉴 구성 |
| calculate_price() | 기본 가격과 선택 옵션의 추가 금액 합산 | 한 잔 가격 계산 |
| CoffeeKiosk.__init__() | 주문 내역, 번호, 선택값을 초기화 | 키오스크 객체 생성 |
| make_widgets() | Notebook, Button, Radiobutton, Checkbutton 등 배치 | 화면 구성 |
| current_item() | 현재 선택한 음료와 옵션을 딕셔너리로 반환 | 주문 항목 생성 |
| add_to_cart() | 주문 항목을 리스트에 저장 | 여러 음료 주문 |
| cart_total() | 각 항목의 단가 × 수량을 모두 합산 | 총액 계산 |
| pay() | 결제 확인 후 영수증 생성, 번호 증가 | 주문 완료 처리 |

수업의 윈도 프로그래밍 자료에서 다룬 사진, 버튼, 라디오버튼, 체크버튼, 대화상자를 활용하였습니다. 객체지향 프로그래밍 자료의 클래스, 생성자, self, 메서드를 적용하여 화면과 주문 처리를 CoffeeKiosk 클래스로 묶었습니다. 탭은 ttk.Notebook, 주문 내역은 ttk.Treeview를 추가로 사용하였습니다.

첨부 캡처는 Linux의 가상 디스플레이에서 실제로 프로그램을 실행해 촬영한 화면입니다. Windows에서는 글꼴이나 창 테두리가 다를 수 있습니다. 제출 전 학교 PC에서 직접 실행하고, 위 순서대로 화면을 다시 캡처하는 것을 권장합니다.

직접 캡처할 때는 **Win + Shift + S**로 프로그램 부분을 선택한 후 이미지 파일로 저장합니다. 주문 완료 팝업을 닫고 영수증이 보이는 화면도 캡처합니다. 제출물에는 소스코드뿐 아니라 images 폴더도 반드시 포함합니다.

프로그램 설명 시에는 메뉴 선택 → 옵션 선택 → 한 잔 가격 계산 → 수량 반영 → 주문 내역 합계 → 모의 결제 → 주문번호 발급 순서로 설명할 수 있습니다.

최신 Windows 검증 21개 항목(가격·수량 조합 720개 포함)과 기존 Linux 검토 기록은 `검토결과.txt`에 기록하였습니다. 실제 Windows 창에서 사진과 결제 취소·완료 대화상자도 확인했습니다. 교수님 PC에서의 실행, 네트워크를 실제로 끊은 상태의 실행은 미확인입니다. 제출용 ZIP은 발견되지 않아 ZIP 해제 검증은 수행하지 않았으며, 대신 새 폴더에 코드와 사진을 복사하여 다른 터미널 위치에서 실행을 확인했습니다. 사진 출처와 이용 조건은 `사진출처.md`에 정리하였습니다.
