# 커피매장 주문용 키오스크

- 이름: 박수용
- 학번: 2601110288

## 1. 제작 내용

Python의 tkinter를 사용하여 커피매장 주문용 키오스크를 제작하였습니다.

커피와 차 메뉴를 탭으로 구분하고, 음료의 온도·용량·추가 옵션·수량에 따라 결제 금액이 계산되도록 구성하였습니다. 선택한 음료를 주문 내역에 담고 결제하면 주문번호와 영수증이 표시됩니다.

수업용 모의 결제 프로그램으로, 실제 카드 결제는 진행되지 않습니다. 주문번호는 프로그램 실행 중 001부터 순서대로 증가하며, 프로그램을 종료하고 다시 실행하면 001부터 시작합니다.

## 2. 과제 조건 반영 내용

| 과제 조건 | 구현 내용 |
|---|---|
| 최소 2종류 이상의 메뉴 탭 | 커피 탭과 차 탭으로 구성하였습니다. |
| 음료 종류별 사진 | 아메리카노·카페라떼·홍차·녹차의 사진을 표시하였습니다. |
| HOT / ICE 선택 | 라디오버튼으로 선택하며, ICE는 500원이 추가됩니다. |
| 용량 선택 | Small 355mL, Medium 473mL, Large 591mL 중 선택할 수 있습니다. |
| 추가 옵션 | 샷 추가와 시럽 추가를 선택할 수 있습니다. 샷 추가는 커피에서만 가능합니다. |
| 결제 금액 산출 | 메뉴·온도·용량·추가 옵션의 금액을 합산한 뒤 수량을 반영합니다. |
| 주문번호 표기 | 결제 완료 안내창과 영수증에 주문번호를 표시합니다. |
| 소스코드 및 실행화면 제출 | Python 소스코드와 Windows 실행화면 캡처 3장을 포함하였습니다. |

차 메뉴는 홍차와 녹차로 구성하였습니다. 메뉴 가격과 추가 금액은 실습용으로 정하였습니다.

## 3. 메뉴와 추가 금액

### 기본 메뉴

| 구분 | 메뉴 | 기본 가격 |
|---|---|---:|
| 커피 | 아메리카노 | 2,500원 |
| 커피 | 카페라떼 | 3,500원 |
| 차 | 홍차 | 3,000원 |
| 차 | 녹차 | 3,000원 |

기본 가격은 HOT, Small, 추가 옵션 없음 기준입니다.

### 온도

| 선택 | 추가 금액 |
|---|---:|
| HOT | 0원 |
| ICE | 500원 |

### 용량

| 선택 | 용량 | 추가 금액 |
|---|---:|---:|
| Small | 355mL | 0원 |
| Medium | 473mL | 500원 |
| Large | 591mL | 1,000원 |

### 추가 옵션

| 옵션 | 추가 금액 | 적용 메뉴 |
|---|---:|---|
| 샷 추가 | 500원 | 커피 |
| 시럽 추가 | 300원 | 커피·차 |

추가 금액은 한 잔 기준으로 적용됩니다. 수량은 1잔부터 10잔까지 선택할 수 있습니다.

## 4. 실행 환경과 방법

### 실행 환경

Windows용 Python 3와 Tcl/Tk가 설치된 환경에서 실행합니다.

사용하는 모듈은 다음과 같습니다.

- pathlib
- tkinter
- tkinter.ttk
- tkinter.messagebox

Python 기본 모듈을 사용하므로 별도의 pip 패키지 설치가 필요하지 않습니다. 사진은 함께 제출한 PNG 파일을 읽어 표시하므로 인터넷 연결이나 API 키도 필요하지 않습니다.

Python이 설치되지 않은 PC에서는 이 Python 소스파일만으로 실행할 수 없습니다.

### 압축 해제

1. 제출한 ZIP 파일을 마우스 오른쪽 버튼으로 클릭합니다.
2. ‘모두 압축 풀기’를 선택합니다.
3. 압축을 푼 폴더에서 coffee_kiosk.py와 images 폴더가 함께 있는지 확인합니다.

ZIP 내부에서 파일만 바로 실행하지 말고, 전체 압축을 해제한 뒤 실행합니다.

### IDLE에서 실행

1. IDLE을 실행합니다.
2. File → Open에서 coffee_kiosk.py를 엽니다.
3. F5를 누르거나 Run → Run Module을 선택합니다.

### PowerShell에서 실행

1. 파일 탐색기에서 coffee_kiosk.py가 있는 폴더를 엽니다.
2. 파일 탐색기의 주소 표시줄에 powershell을 입력하고 Enter를 누릅니다.
3. 열린 PowerShell 창에 다음 명령을 입력합니다.

```powershell
python coffee_kiosk.py
```

VS Code를 사용하는 경우에도 해당 폴더를 열고 터미널에서 같은 명령을 입력하면 됩니다. VS Code는 필수 실행 도구가 아닙니다.

사진 경로는 소스파일 위치를 기준으로 처리합니다. 폴더를 다른 위치로 옮기더라도 coffee_kiosk.py와 images 폴더를 함께 유지해야 합니다.

## 5. 사용 방법

1. 커피 또는 차 탭을 선택합니다.
2. 주문할 음료의 사진을 누릅니다.
3. HOT 또는 ICE를 선택합니다.
4. 용량을 선택합니다.
5. 필요한 추가 옵션과 수량을 선택합니다.
6. 화면에 표시된 금액을 확인하고 ‘주문 담기’를 누릅니다.
7. 다른 음료를 주문하려면 같은 과정을 반복합니다.
8. 전체 주문 내역과 총 결제 금액을 확인합니다.
9. ‘결제하기 (모의 결제)’를 누릅니다.
10. 결제 확인창에서 ‘예’를 선택합니다.
11. 완료 안내창과 영수증에서 주문번호와 결제 금액을 확인합니다.

메뉴를 변경하면 선택 옵션은 HOT, Small, 추가 옵션 없음, 수량 1잔으로 초기화됩니다. 이미 주문 내역에 담은 음료의 옵션은 유지됩니다.

### 주문 수정

- 선택 삭제: 주문 내역에서 항목을 선택한 뒤 누르면 해당 항목만 삭제됩니다.
- 전체 비우기: 담긴 주문을 모두 삭제합니다.
- 결제 취소: 결제 확인창에서 ‘아니요’를 선택하면 주문 내역과 주문번호가 유지됩니다.
- 빈 주문: 음료를 담지 않은 상태에서는 결제를 진행하지 않습니다.

## 6. 결제 금액 계산 예시

한 잔 가격은 다음과 같이 계산합니다.

```text
한 잔 가격 = 기본 가격 + 온도 추가 금액 + 용량 추가 금액 + 옵션 추가 금액

항목별 금액 = 한 잔 가격 × 수량

총 결제 금액 = 모든 주문 항목의 금액 합계
```

### 아메리카노 2잔

선택 조건:

- ICE
- Large
- 샷 추가
- 시럽 추가
- 수량 2잔

```text
한 잔 가격
= 2,500 + 500 + 1,000 + 500 + 300
= 4,800원

두 잔 가격
= 4,800 × 2
= 9,600원
```

### 홍차 1잔

선택 조건:

- HOT
- Small
- 추가 옵션 없음
- 수량 1잔

```text
한 잔 가격
= 3,000 + 0 + 0 + 0
= 3,000원
```

### 전체 결제 금액

```text
아메리카노 2잔 + 홍차 1잔
= 9,600 + 3,000
= 12,600원
```

프로그램 실행 후 첫 결제를 완료하면 주문번호 001이 표시되고, 다음 주문번호는 002가 됩니다.

결제가 완료되면 주문 내역과 총액은 초기화되며, 최근 주문 영수증은 화면에 남습니다. 이때 상단의 총 결제 금액 0원은 새 주문의 금액이며, 완료된 주문의 결제 금액은 영수증에서 확인할 수 있습니다.

## 7. 주요 코드 설명

| 코드 | 설명 | 역할 |
|---|---|---|
| MENUS | 메뉴 이름·기본 가격·사진 파일명을 저장합니다. | 메뉴 구성 |
| TEMPERATURE_PRICE | HOT과 ICE의 추가 금액을 저장합니다. | 온도별 가격 설정 |
| SIZE_PRICE | 용량별 추가 금액을 저장합니다. | 용량별 가격 설정 |
| OPTION_PRICE | 샷과 시럽의 추가 금액을 저장합니다. | 옵션별 가격 설정 |
| IMAGE_DIR | 소스파일 위치를 기준으로 사진 폴더를 지정합니다. | 사진 경로 처리 |
| calculate_price() | 기본 가격과 선택한 옵션의 금액을 합산합니다. | 한 잔 가격 계산 |
| CoffeeKiosk.__init__() | 주문 내역·주문번호·선택값을 초기화합니다. | 초기 상태 설정 |
| make_widgets() | 탭·버튼·선택 항목·주문 내역을 배치합니다. | 화면 구성 |
| select_menu() | 음료를 선택하고 옵션을 초기화합니다. | 메뉴 선택 처리 |
| current_item() | 현재 선택한 음료·옵션·수량·단가를 반환합니다. | 주문 항목 생성 |
| add_to_cart() | 선택한 음료를 주문 내역에 추가합니다. | 주문 담기 |
| refresh_cart() | 주문 내역과 총액을 화면에 반영합니다. | 주문 화면 갱신 |
| cart_total() | 각 주문 항목의 금액을 합산합니다. | 총액 계산 |
| remove_selected() | 선택한 주문 항목을 삭제합니다. | 개별 주문 삭제 |
| clear_cart() | 주문 내역을 모두 비웁니다. | 전체 주문 삭제 |
| pay() | 결제를 확인하고 영수증과 주문번호를 처리합니다. | 주문 완료 처리 |

화면과 주문 처리는 CoffeeKiosk 클래스로 구성하였습니다. 생성자에서 초기 상태를 설정하고, 각 기능을 메서드로 나누었습니다.

화면에는 tkinter의 Label, Button, Radiobutton, Checkbutton과 대화상자를 사용하였습니다. 메뉴 탭은 ttk.Notebook, 용량과 수량 선택은 ttk.Combobox, 주문 내역 표시는 ttk.Treeview를 사용하였습니다.
